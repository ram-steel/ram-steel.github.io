Project Overview

This project covers the in-workshop fabrication of primary structural steel members — built-up box columns and H-section beams — for a hot-rolled steel structure. Each member was cut, welded, and drilled to shop drawings, then finished with anti-corrosion primer paint before being shrink-wrapped on timber pallets, ready for transport and site erection.
